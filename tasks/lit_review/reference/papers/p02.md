# p02. __BenchA__: a controlled benchmark for __TopicShort__, and the __FailureModeShort__ problem

- Authors: P. Varga, N. Adeyemi
- Venue: __VenueA__ 2020
- Index id: p02

## Abstract

Progress on __Topic__ has been hard to compare because each paper evaluates on a task of its own design. We introduce __BenchA__, __BenchAGloss__, with items at __ScaleLow__, __ScaleMid__ and __ScaleHigh__. We also define __Metric__, accuracy on __BenchA__ divided by the oracle upper bound for that setting, so that it lies in [0, 1] by construction and is comparable across settings. Using __BenchA__ we re-evaluate __Method1__ [p01] and an unmodified baseline. Two findings stand out. First, __Method1__'s reported __ScaleMid__ result reproduces (we obtain 0.59 against the reported 0.60). Second, we document __FailureMode__. This failure mode is invisible to aggregate accuracy and accounts for most of the gap between __Method1__ and the oracle at __ScaleMid__. We release __BenchA__ with a fixed evaluation protocol. Finally, we note a problem that __BenchA__ does not measure and that no current method addresses: __OpenProblem__. We argue that any claim about __TopicShort__ should state explicitly whether it covers this case, because in our preliminary experiments every method we tried falls to baseline there.
